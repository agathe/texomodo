TexoModo

Comment on a website, right on the page.

TexoModo adds a Review Mode to a static website. Reviewers open the site, sign in with Google, click an element or draw on the page, and leave a comment. Maintainers verify, resolve and keep an audit trail. Visitors never see any of it.

What it does

  • Comments anchored to elements, shapes, shared components like the header, or site-wide style rules.
  • Phone, tablet and desktop frames, so a comment says which sizes it applies to.
  • Per-site reviewer lists by Google Workspace domain or individual account. Roles for reviewers and maintainers.
  • Every change logged: who edited, moved, verified or resolved what, and on which build.
  • One script tag per page. Nothing loads until the review button is clicked.

Where it is

Private beta, in use on one church website redesign. Coming next: turning a verified comment into a proposed change, reviewed as a pull request with a preview.

Built on Supabase and Netlify. Comments are stored per site, protected by database policies, and visible only to that site's reviewers.
